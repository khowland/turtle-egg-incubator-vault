## Root Cause of Remaining 4 Failures

### Timeout on SAVE Button Click (tests 2, 3, 5)
After the SAVE button is clicked and `at.run(timeout=15)` is called, the script re-executes and must: (a) retrieve eggs_data from Supabase, (b) query observation logs, (c) optionally query hatchling ledger entries, (d) insert observations, (e) update egg stage, (f) write audit logs. All these Supabase operations take 10-30 seconds in the AppTest environment. The 15-second timeout is too short.

### Timeout on Surgical Rerun (test 4)
After selecting S4 in surgical mode and calling `at.run(timeout=15)`, the script must load observations which takes 63+ seconds (confirmed in log output). The 15-second timeout is insufficient; the surgical test also fails later at `at.run(timeout=120)` which itself hangs infinitely. The surgical mode rerun needs at least 120 seconds.
